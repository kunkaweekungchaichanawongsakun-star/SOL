# EP02 · ไล่ความสมเหตุสมผล SB02-18 ถึง 32 · 2026-10-21

ไล่จากพรอมป์ที่ยิงไปแล้ว ด้วยหลักที่ user สอนวันนี้ ยังไม่ได้แก้อะไร และไม่ได้ยิงอะไร
ผมเปิดวิดีโอไม่ได้ ข้างล่างนี้จึงเป็น **ความเสี่ยงที่อ่านออกจากพรอมป์** user ต้องเอาไปเทียบกับเทคจริงเอง

ระดับความเสี่ยง
- 🔴 คนดูทั่วไปเห็นว่าแปลก หรือผู้กำกับน่าจะสั่งแก้
- 🟡 เสี่ยงเล่นเกินหรือจังหวะสุ่ม
- ⚪ เล็กน้อย

## ทุกบ็อกตั้งแต่ SB02-19 ถึง 32
- **บีตไม่มีวินาที (ด่าน A23):** ลำดับเหตุ → การกระทำ → บทพูดจึงสุ่มได้ในทุกบ็อกนี้
- **แท็กจีนใต้บทพูด:** เก็บไว้ เพราะเป็นเวิร์กโฟลว์ของผู้กำกับ
